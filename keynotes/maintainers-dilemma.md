# The Maintainer's Dilemma
## Open Source and AI
- Anyone can participate
    - Sheer amount of PRs
    - Quality can be subpar
    - Security risks
## What does good AI look like
- Write down the rules
    - CONTRIBUTING.md
- Repo readiness
    - AGENTS.md
        - provides context for agents
    - SKILL.md
        - Workflows
        - how to do things in this codebase
## AI reviews
- Triage issues
- Use AI to review AI
- Security scans
- Agent merges
## Discuss first
- discuss the issue on github before coding
- PRs then more likely to be merged
